📌 About The Project

HMG.exe is a Python project designed to represent a basic Hospital Management System.

The project uses Object-Oriented Programming (OOP) to organize hospital-related information and operations into separate classes and modules.

✨ Features

👨‍⚕️ Doctor Management

🧑 Patient Management

📅 Appointment Management

🏥 Hospital Information Management

🧩 Object-Oriented Programming

🐍 Modular Python Structure
